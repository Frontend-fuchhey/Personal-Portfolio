# Shrawan OS

An OS-style interactive portfolio of Shrawan Karki, built as a desktop/mobile "operating system" in the browser.

**Live:** https://shrawankarki.com.np

## Apps

- **About** - who I am
- **Projects** - things I've built
- **Photos** - photo gallery
- **Terminal** - command-line interface
- **Resume** - view my resume
- **Contact** - send me a message
- **Settings** - wallpapers and preferences

## Tech Stack

React 19, TypeScript, Vite, Tailwind CSS, Framer Motion, Firebase, Netlify Functions.

## Run Locally

```bash
npm install
cp .env.example .env
npm run dev
```

Build for production with `npm run build`.
